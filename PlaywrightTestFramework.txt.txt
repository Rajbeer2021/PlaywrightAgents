import { test, expect } from '@playwright/test';

test('Valid login', async ({ page }) => {

    await page.goto('https://example.com');

    await expect(page).toHaveTitle(/Example/);

});

Explanation

test() defines the test case.

'Valid login' is the test title.

page is a built-in Playwright fixture.

async and await handle asynchronous browser actions.

expect() performs assertions.


Note - Playwright's built-in fixtures provide ready-to-use test dependencies such as page, browser, context, and request.

@beforeClass - test.beforeAll()
@afterClass  - test.afterAll()


# note in playwright, we use test.beforeAll(), test.afterAll() in place of @beforesuite, @aftersuite, @abeforetest, @afterTest..

   @Test   === test('name', async ({}) => {}) - Declares a fundamental test case.
 
1. @Test(enabled = false)      === test.skip(). --> Bypasses the execution of that specific test.
2. @Test(groups = {"smoke"})   === tags: ['@smoke'] or @smoke in title. --> Labels tests for conditional running via command-line grep.

3. @Test(timeOut = 5000)       === test.setTimeout() or test.slow() --> Overrides or triples the duration limit for a slow test.

4. @DataProvider   ===  test.describe.configure() or for...of loops  --> Loops over an array of data dynamically to generate multiple test instances.
